Privacy

This website

This site has no cookies, no analytics, no trackers and no third-party fonts or scripts. It is hosted on GitHub Pages; GitHub logs the IP addresses of visitors for security and operation. To show the newest version, the download section and the beta page ask GitHub's public API (api.github.com) for the list of releases, directly from your browser; GitHub receives your IP address for that request. See GitHub's privacy statement for details.

The app

Corewright runs entirely on your PC. It does not send your data anywhere. The only outgoing request is the update check: once a day while the window is open, or when you choose Check now, it asks GitHub's public API for the newest release of your update channel; GitHub receives your IP address for that request. Its HTTP API listens only on 127.0.0.1 and needs a token that changes at every start. Rules, settings and the history Autopilot learns stay in Corewright's data folder on your PC.
